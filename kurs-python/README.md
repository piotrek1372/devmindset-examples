# DevMindset — Python od zera: materiały do filmów

Pobierz ZIP dla swojego odcinka, rozpakuj go i zacznij od `START-TUTAJ.md` oraz `run.md`. Pliki `code/` odpowiadają przykładom w filmie; w odcinku 5 zadania startowe są w `start/`. Rozwiązania otwieraj po własnej próbie.

| Odcinek | Temat | Paczka |
|---|---|---|
| 1 | Pierwszy program i print | [DevMindset-01-cwiczenia.zip](DevMindset-01-cwiczenia.zip?raw=true) |
| 2 | Zmienne, input i kalkulator | [DevMindset-02-cwiczenia.zip](DevMindset-02-cwiczenia.zip?raw=true) |
| 3 | if, elif, else | [DevMindset-03-cwiczenia.zip](DevMindset-03-cwiczenia.zip?raw=true) |
| 4 | while, for i range | [DevMindset-04-cwiczenia.zip](DevMindset-04-cwiczenia.zip?raw=true) |
| 5 | Listy, słowniki i rejestr napraw | [DevMindset-05-cwiczenia.zip](DevMindset-05-cwiczenia.zip?raw=true) |

Zatrzymuj film na czas pisania i uruchamiania kodu. Minuty pracy oznaczają samodzielną pracę po ręcznym zatrzymaniu, chyba że w filmie jest jawne odliczanie. Pliki z celowym błędem są opisane w ćwiczeniach. Nie są potrzebne klucze API ani płatne usługi.

W odcinku 5 `calculator-changes.diff` pokazuje zmiany pełnego kalkulatora, a `start/00-recall.py` rozpoczyna przypomnienie pętli.
